# Recipes

A small static recipe site: searchable list, per-recipe scaling (½x to 3x), standard units and grams side by side, tap-to-check ingredients and steps, a keep-screen-awake toggle, and a print stylesheet. Plain HTML, CSS and JavaScript. No framework, no bundler, no dependencies.

Live: https://wtennis.github.io/recipes/ (GitHub Pages, served from the root of `main`)

## Quick start

```sh
node scripts/build.js      # validate recipes/*.json and regenerate recipes/index.json
node scripts/test-format.js  # tests for the fraction / grams / scaling helpers
npx serve .                # preview at http://localhost:3000
```

Open `recipe.html?r=<slug>` for a recipe; add `&x=1.5` to preload a scale.

## Adding a recipe

The `/create-recipe <URL or idea>` Claude Code skill does this end to end (fetch or develop the recipe, fill in gram weights, validate, preview, commit and push). The skill is global: it lives in `~/.claude/skills/create-recipe` (not in this repo), so it works from any directory.

By hand: write `recipes/<slug>.json` following [SCHEMA.md](SCHEMA.md), run `node scripts/build.js`, commit `recipes/`, push.

## Structure

```
index.html            recipe list (search, tag chips, cards)
recipe.html           single recipe renderer
css/style.css         styles, dark mode, print
js/common.js          shared helpers (fraction/grams formatting, scaling, fetch); also runs in Node
js/index.js           list page logic
js/recipe.js          recipe page logic
recipes/<slug>.json   one file per recipe (source of truth)
recipes/index.json    GENERATED by scripts/build.js; do not edit
scripts/build.js      validator + index generator
scripts/test-format.js  tests for js/common.js
SCHEMA.md             recipe JSON format
serve.json            local-preview setting for `npx serve` (keeps ?r=<slug> from being dropped by clean-URL redirects)
```

All URLs are relative, so the site works from the `/recipes/` subpath on GitHub Pages and from a local server.
